# 数据与隐私说明

## 收集的数据

插件仅为账号绑定和访问控制保存以下数据：

- QQ 用户 ID
- Minecraft 玩家名及其规范化形式
- 绑定、解绑和迁移时间
- 管理操作与群事件的最小审计记录
- 开启入群验证时的验证码摘要、有效期和尝试次数

插件不保存 QQ 密码、Cookie、二维码、好友列表或完整群聊历史。

## 存储与访问

数据保存在 BungeeCord 主机的本地 SQLite 数据库中，不会由插件上传到第三方服务。
只有代理进程和受授权的服务器管理员应拥有文件访问权限。后端 Bukkit/Spigot
服务器不得直接读取或修改代理数据库。

## 数据删除

- 群管理员可按 QQ 或 Minecraft ID 解除绑定。
- 可配置成员离群后自动解除绑定。
- 运行数据库和审计记录的保留周期由服务器运营者根据实际需要制定。
- 删除或导出个人记录时，应先停服或使用数据库一致性备份，避免损坏运行数据库。

## 公开仓库

公开仓库不包含生产数据库、白名单、Token、群号、管理员 QQ、日志、二维码或安装包。
